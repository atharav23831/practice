# Paradise Nursery – Online Plant Shop

## Project Name
Paradise Nursery

## Project Description
Paradise Nursery is an online plant shopping application that allows users to explore and purchase a variety of indoor and outdoor plants. The application provides a user-friendly interface for browsing plants, adding products to the shopping cart, and managing cart items.

## Features
- Landing page with company name, background image, and Get Started button.
- Product listing page displaying plants with their details and prices.
- Add plants to the shopping cart.
- Remove items from the shopping cart.
- Update product quantities.
- View the shopping cart and total price.
- Responsive and user-friendly interface.

## Technologies Used
- React.js
- JavaScript
- CSS
- Redux Toolkit for state management

## Project Structure
- `App.jsx` – Main application component and landing page.
- `App.css` – Styling and background image implementation.
- `AboutUs.jsx` – Company information.
- `ProductList.jsx` – Plant product listing page.
- `CartItem.jsx` – Shopping cart page.
- `CartSlice.jsx` – Cart reducer functions for adding, removing, and updating quantities.

## Purpose
The purpose of this project is to develop an interactive online plant shop that demonstrates React component development, state management, and shopping cart functionality.
